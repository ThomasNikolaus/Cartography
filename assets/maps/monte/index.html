Homotopical Cartography Project

Monte map sheets

Sixty numbered illustrations for Exploration Charts, from Urbano Monte’s world map of 1587. File numbers 01–60 follow the historical sheet numbers. Each image is a compact WebP preview, up to 400 pixels wide, suited to the small illustrations beside PDF links.

The original paper edges are preserved. Source links lead to the David Rumsey Map Collection. New Charts can select a sheet by number; existing illustrations keep their current assignment.
